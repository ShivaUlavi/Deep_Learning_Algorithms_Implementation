## 💡 About The Project

As a Data Professional with a Master of Science in Business Analytics, I created this repository to bridge the gap between theoretical mathematics and practical, scalable code. Here, you will find:
* **From-Scratch Implementations:** Core algorithms built using pure NumPy to understand the math behind backpropagation, gradient descent, and forward passes.
* **Framework Implementations:** Scalable models built using **TensorFlow**, **PyTorch**, and **Keras** for computer vision, time-series forecasting, and more.

## 🛠 Key Implementations

*This section is continuously updated as new algorithms are added.*

* **Deep Neural Networks (DNNs):** Multi-layer perceptrons with custom activation functions (ReLU, Sigmoid, Softmax) and optimization algorithms (Adam, RMSprop).
* **Convolutional Neural Networks (CNNs):** Image classification, 2D scene understanding, and spatial feature extraction.
* **Recurrent Neural Networks (RNNs & LSTMs):** Sequence modeling and time-series forecasting.
* **Clustering & Anomaly Detection:** Unsupervised learning architectures applied to high-dimensional datasets.

## ⚙️ Tech Stack

* **Languages:** Python 3.x, SQL
* **Deep Learning:** TensorFlow, PyTorch, Keras
* **Data Manipulation & Math:** NumPy, Pandas, SciPy
* **Data Visualization:** Matplotlib, Seaborn
